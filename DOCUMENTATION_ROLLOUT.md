## How to use this index

Each linked PR contains the project-specific documentation kit or portfolio notes. Review the full diff before merging. Documentation PRs are separate from code fixes and do not certify runtime behavior.

The standard project kit contains:
- `ACTIVITY_LOG.md`
- `FEATURE_UPGRADE_PLAN.md`
- `COMPANY_FIT.md`
- `README_ADDENDUM_DRAFT.md`
- `README_QUALITY_CHECKLIST.md`
- `CONTRIBUTING.md` (new where absent; otherwise preserved)
- `AGENTS.md` and `SKILLS.md` where suitable
- README links and a plain-language plus technical/research guide

The four upstream forks use `PORTFOLIO_NOTES/` instead of overwriting upstream documentation or agent instructions.

## Review and merge policy

1. Verify project-specific descriptions against source code.
2. Check for duplicated or conflicting README/CONTRIBUTING/AGENTS instructions.
3. Run relevant tests only after reviewing the actual diffs; docs-only PRs do not prove runtime correctness.
4. Keep branch protections, human reviews and licensing requirements intact.
5. Merge only after the repository owner approves. No PR in this rollout was merged by this process.
