# Dream-Catcher — Feature Upgrade Plan

## Objective

Maintain an accurate, useful and evidence-backed map of companies, public engineering work, relevant teams, roles and portfolio proof points.

## P0 — freshness and source integrity

- [ ] Verify every company profile against current official newsroom, research, leadership and careers pages.
- [ ] Separate publication date from event date; mark outdated role titles.
- [ ] Add source freshness status and next review date per profile.
- [ ] Validate links and archive changed/removed official pages with retrieval date.

## P1 — career targeting workflow

- [ ] Add role tracker linking an active official job description to required skills and supporting repositories.
- [ ] Score fit using explicit skill evidence, not brand prestige or guessed hiring likelihood.
- [ ] Add application status, public job URL, deadline and tailored evidence checklist.
- [ ] Create one-page project evidence briefs for the highest priority roles.

## P2 — intelligence quality

- [ ] Add source-diff monitoring for company research pages.
- [ ] Add a structured schema for companies, projects, people, roles, sources and repository mappings.
- [ ] Add deduplication, contradiction flags and human review for people/title data.
- [ ] Add public role/team updates only when explicitly confirmed by official public sources.

## Definition of done

- [ ] Every factual claim links to an official source and date.
- [ ] Every people entry is a public professional role or explicitly credited contributor.
- [ ] Private contact details, personal-life facts and sensitive data are excluded.
- [ ] Each repository has at least one plausible target employer and a concrete evidence gap to close.
- [ ] A reviewer can reproduce the source check and understand uncertainty.
