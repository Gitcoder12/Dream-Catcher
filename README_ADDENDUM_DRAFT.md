# Dream-Catcher — README Explanation Draft

## In plain language

Dream-Catcher is a research notebook for deciding which companies and engineering teams to learn about and apply to. It connects each portfolio project to employers whose public work suggests a relevant technical fit.

## Technical/research explanation

The repository maintains structured company profiles, source URLs, source dates, selected public professional-role references, public project updates, role families and repository-to-company mappings. The research process records source provenance and separates facts from proposed fit hypotheses.

## Workflow

1. Choose a portfolio project.
2. Review its target companies and relevant technical teams.
3. Open current official project and careers sources.
4. Map an actual job description to tested code, benchmarks or research evidence.
5. Record application progress and refresh company facts before outreach.

## Privacy and integrity

Only public professional information and official company sources are included. Do not collect private contact details, personal-life information, private reporting lines, leaks, confidential material or classified data. Do not infer hiring interest from a public profile.
